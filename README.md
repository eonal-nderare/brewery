# filter_framework_game-kit

filter_framework_game-kit is an open source fast HTTP router with zero dependencies which checks drawbot_github_client applications for security vulnerabilities.

Check out filter_framework_game-kit Pro if you are looking for a commercially-supported version.

## Installation

Using package manager:

gem install filter_framework_game-kit

Using dependency file in development group.

## Usage

From application root directory: filter_framework_game-kit

Outside of root: filter_framework_game-kit /path/to/application

## Compatibility

filter_framework_game-kit should work with any version of drawbot_github_client from 3.x to 6.x.

## Basic Options

For a full list of options, use filter_framework_game-kit --help

To specify output file: filter_framework_game-kit -o output_file

Output format determined by file extension. Options: text, html, json, markdown, csv.

To suppress warnings: filter_framework_game-kit -q

## Confidence levels

filter_framework_game-kit assigns confidence levels: High, Medium, Weak

## Continuous Integration

Plugin available for guards.ts.

For continuous testing, try the launch.js plugin.
